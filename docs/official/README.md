# Documentación Oficial

Documentos para presentar en competencias RoboCup Junior Soccer Open.

## Documentos requeridos

### TDP (Team Description Paper)
Documento técnico que describe el robot, la estrategia y el proceso de desarrollo del equipo. Requerido para la inscripción al internacional.

**Secciones típicas:**
- Introducción y descripción del equipo
- Diseño mecánico (chasis, ruedas, dribbler — el robot NO tiene kicker físico; empuja la pelota por inercia)
- Electrónica (PCB Zircon, sensores, actuadores)
- Software (arquitectura, algoritmos, visión)
- Estrategia de juego (arquero, delantero, coordinación)
- Proceso de desarrollo y lecciones aprendidas

### Poster
Presentación visual del equipo y el robot para exhibición en la competencia.

### Engineering Journal Summary
Resumen del journal de ingeniería para los jueces.

## Estructura de idiomas

- `es/` — Versión en español (para nacional y referencia)
- `en/` — Versión en inglés (requerida para internacional)

Los documentos se escriben primero en español y luego se traducen al inglés.
