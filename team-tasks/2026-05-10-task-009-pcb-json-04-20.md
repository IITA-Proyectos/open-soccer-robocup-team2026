# TASK-009 — Subir archivos EasyEDA del 04-20

## Por qué importa

Hoy (2026-05-10) verificamos que el **BOM** de la placa Base es idéntico entre el design 04-12 (que ya estaba en el repo) y el 04-20 (que vos subiste). Pero el BOM no determina el routing — solo el conjunto de partes.

En la auditoría que hice hoy del PCB JSON 04-12 detecté **10 nets sin rutear** que impactan funcionalidad crítica:

- `O1`, `O2`, `O3` (salidas de 3 de los 4 muxes CD4051) → **24 de los 32 sensores de línea no funcionarían**.
- `SDA1`, `SCL1` (bus I2C del segundo OTOS) → **uno de los 2 OTOS no se conectaría al Teensy**.
- `E1`, `E6`, `E7`, `E11` (señales de control de muxes) → degradación adicional.

Ver `research/in-progress/2026-05-10-auditoria-pcb-down-unrouted-nets.md`.

Si vos **cambiaste el routing entre 04-12 y 04-20** antes de mandar a fabricar (lo cual es lo más probable y esperable), las placas físicas que llegaron pueden estar OK y la auditoría del 04-12 quedó stale. Pero para confirmarlo necesitamos los archivos del proyecto, no solo los Gerbers de fabricación.

## Cómo se exporta desde EasyEDA

1. Abrir el proyecto en EasyEDA editor (web o desktop).
2. Para cada documento (PCB y Schematic):
   - **File → Export → EasyEDA Source** → guarda como `.json`.
   - **File → Export → PDF** → guarda como `.pdf`.
3. Guardar los archivos en las rutas indicadas arriba.
4. Commit + push.

Alternativa: si te resulta más fácil, podés usar **File → Export → JSON of this Document** o **BackupProjects** (que es el zip que ya usaste para los del 04-12 y mantiene mismo formato).
